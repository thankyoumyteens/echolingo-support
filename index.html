EchoLingo Support

Translate text

Open the Translate tab, choose a target language, and enter up to 300 characters. Apple system translation is selected by default. If prompted, download the required language resources.

On iOS or iPadOS 18.4 or later, search Settings for “Default Apps,” then select EchoLingo as your translation app. In a supported app, select text and choose Translate.

Connect your own translation service

In EchoLingo settings, add the endpoint, model name, and API key from your OpenAI-compatible service. For help with authentication, availability, billing, or the deletion of data already sent to that service, contact the provider.

Get help

When reporting an issue, include your EchoLingo and iOS or iPadOS versions, the translation engine and language pair, and steps to reproduce it. Use sample text and omit API keys, private text, and unredacted diagnostic files.

Contact EchoLingo support on GitHub. Issues are public. Do not include private text, credentials, or personal details.

EchoLingo 支持

翻译文字

打开「翻译」，选择目标语言，输入不超过 300 个字符的文字。App 默认使用 Apple 系统翻译。若系统提示下载所需语言资源，按提示操作。

在 iOS 或 iPadOS 18.4 及以上版本，可在系统设置中搜索「默认 App」，将 EchoLingo 设为默认翻译 App。随后可在支持的 App 中选中文字并选择「翻译」。

连接自己的翻译服务

在 EchoLingo 设置中填写兼容 OpenAI 的服务地址、模型名称和 API 密钥。服务认证、可用性、费用以及已发送数据的删除由所选服务商处理。

报告问题

请提供 EchoLingo 版本、iOS 或 iPadOS 版本、所用引擎、语言对和复现步骤。请使用示例文本，并移除 API 密钥、私人文本和未脱敏的诊断文件。

在 GitHub 联系 EchoLingo 支持。问题记录公开，请勿填写私人文本、密钥或个人信息。
