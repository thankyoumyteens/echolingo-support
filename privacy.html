EchoLingo Privacy Policy

EchoLingo offers Apple system translation and an optional bring-your-own-key translation mode.

Apple system translation

Apple system translation is the default. This mode does not require an EchoLingo account, a third-party endpoint, or an API key. Your device may download Apple language resources to use the selected language pair.

Optional third-party translation

If you choose a provider, EchoLingo sends requests directly to the endpoint you configured. A translation or pronunciation request can include the text you submit, relevant context, prompt instructions, and the selected model name. The API key authenticates requests to your chosen endpoint. The endpoint may also receive ordinary network information such as your IP address. The provider’s own policies and your account settings govern its retention, use, and deletion of the information it receives.

To stop sending new requests to a provider, switch to Apple system translation or remove that provider. Removing a provider or deleting local history does not remove data already sent to the provider. Contact the provider for its deletion options.

On-device data and backups

EchoLingo stores settings, prompts, translation history, and favorites on your device. Provider API keys are stored in Keychain. The main app and system translation extension share the information they need to use the same settings and records. If you export a backup, you choose where to save it. Ordinary backups exclude API keys. The separate credential export is password-protected.

You can delete history, favorites, and provider configurations in EchoLingo. Manage or delete exported backup files wherever you saved them.

Contact EchoLingo support on GitHub. Issues are public. Do not include private text, credentials, or personal details.

EchoLingo 隐私政策

EchoLingo 提供 Apple 系统翻译，也可选用自带 API 密钥的第三方翻译服务。

Apple 系统翻译

App 默认使用 Apple 系统翻译。此模式无需 EchoLingo 账号、第三方服务地址或 API 密钥。设备可能会下载所选语言对需要的 Apple 语言资源。

可选的第三方翻译

选择第三方翻译服务后，EchoLingo 会直接向您配置的服务地址发送请求。翻译或发音请求可能包含您提交的文本、相关语境、提示词指令和所选模型名称。API 密钥用于向该服务验证请求。服务商也可能收到 IP 地址等常规网络信息。服务商收到数据后的留存、使用和删除，取决于其隐私政策及您的账号设置。

如需停止向该服务发送新请求，可以切换回 Apple 系统翻译或移除该服务配置。移除配置或清空本地历史无法删除已经发送给服务商的数据。如需删除已发送的数据，请联系所选服务商。

设备上的数据和备份

设置、提示词、翻译历史和收藏存储在设备上。API 密钥保存在系统钥匙串中。主 App 与系统翻译扩展共享完成翻译所需的设置和记录。导出备份时，保存位置由您选择。普通备份不包含 API 密钥。密钥可另行导出为密码保护的备份。

您可以在 EchoLingo 中删除历史、收藏和服务配置。已导出的备份可在其保存位置管理或删除。

在 GitHub 联系 EchoLingo 支持。问题记录公开，请勿填写私人文本、密钥或个人信息。
